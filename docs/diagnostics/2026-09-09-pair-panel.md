# Pair 运行台：实现与验收

## 使用

重新加载安装了此工作区版本的 DSH Web 宿主后，打开原 Pair 会话，在会话视图选择 **Pair 运行台**。支持 `sidebarRightTabs` 的宿主也可从右侧栏新增同名面板。旧宿主没有该服务时，会话视图仍然可用。此次实现没有重启用户正在运行的宿主。

显示设置提供舒适/紧凑密度、暂停/恢复更新；密度保存在浏览器本地。暂停仅停止此面板的读取，不会暂停团队。需要新数据的筛选、分页、任务和团队选择在暂停时停用。总览、任务和进展记录可以切换；任务支持全板搜索、筛选、分页和展开详情。

## 信息与含义

- 圆环：完成卡数 / 所有任务卡数，失败、取消和草稿卡也保留在分母中；不将模型自报百分比作为进度。
- 需求验收：目标验收条目中已有完成任务覆盖的数量，使用现有 `goalCoverage` 投影。
- 看板凭证：任务绑定的最新质量凭证仍匹配当前看板。**没有在面板中重跑 Git、oracle 或集成检查**，不能替代真实完成门禁。
- 集成记录：双 Driver 的落盘集成收据数量；单工作区显示不适用。
- 当前重点：复用 `attentionSet`，中文行动在前，原始依据按需展开。
- 席位：持久化的工作/待命状态；续跑预算耗尽来自 `truncatedSeats`。不推测调度器内存中的暂停状态。
- 产品发现、风险、依赖、验收条件、设计职责与协作契约、最近周期和命令修复记录。
- 信箱：可投递消息数。租约中或已确认的消息不计入；宿主接收不代表模型已读。
- 时间线：从任务、周期、判决、命令修复和集成记录导出最近事件。不会伪造未记录的中间步骤。

## 设计边界

主机通过 DSH `connection.rpc.handle('/pair-runtime', ...)` 暴露 `snapshot/watch` 两个只读端点，沿用宿主身份校验。浏览器只传会话、团队与筛选标识，不提供磁盘路径。服务端先从真实 Session header 或 sessionQuery 的持久化观察取得工作区，再筛选该会话担任 Captain 或成员的团队。

只读取规范运行盘。双 Driver 工作树使用现有协调工作区映射；无需另建状态镜像。不调用模型、不发送成员消息、不执行 shell，不向 session log 追加 `pair/*` 事件，保留会话恢复的事件守卫。

更新使用文件夹监听与有界长轮询，监听后再次读取，覆盖原子替换与监听安装之间的竞态。断开请求、隐藏页面、移出可见区域、切换会话及卸载时取消读取；同一订阅仅有一个在途请求。服务卸载会取消所有长轮询。无事件时最多等待 20 秒，监听不可用时 3 秒回退；断线指数退避至 30 秒，保留上次成功状态并明确标记断线。多面板独立订阅，主机上限 32 个在途读取。

读取有界：每次最多检查 128 个团队目录（每盘 8 MiB），每页 24 张任务，最多 12 个成员、8 项重点/风险、24 条事件、12 个详情周期。信箱 2 MiB 以上显示未知。跳过或损坏的数据显式提示，不冒充零进度。大盘搜索先全板匹配再分页。

客户端不新增运行依赖，使用 DSH 提供的 React、locale、connection 和 slots。设置页面源文件保留在 `lib/client/settings.js`；面板组件与 CSS 分离，`scripts/build-client.mjs` 生成兼容原模块加载器的 `lib/client.js`。构建一致性有回归检查。

## 验证方法

`tests/panel.test.mjs` 挂载真实 DSH **SessionStore、HostConnectionService、RPC HTTP 桥**，覆盖授权入口、会话隔离、原子写后刷新、信箱变化、首次建队、取消/卸载和持久化观察释放。HTTP listener、认证策略及浏览器槽位是明确标记的夹具；这不等于启动完整 DSH Web profile。

浏览器预览复用生产面板组件和 CSS，经同一真实 DSH 数据桥读取临时示例盘，验证宽屏、窄栏、深色、动态进度、显示配置、搜索、详情与暂停。示例入口明确标注“非真实团队”。不启动 Agent，不调用模型。现有设置、真实宿主工具注册、启动和打包检查另行执行。

本地运行预览：先将 React 18 与 ReactDOM 18 的 UMD 包装入临时依赖目录，设置 `PAIR_PANEL_PREVIEW_DEPS` 指向其 node_modules，再运行 `node scripts/preview-panel.mjs`。默认路径为系统临时目录下 `pair-panel-preview-deps/node_modules`。页面上“推进示例任务”只修改这个进程创建的临时示例盘。

## 维护

编辑 `lib/client/panel.js` 或 `panel.css` 后运行 `node scripts/build-client.mjs`，不要手改生成文件。新协议字段应先核对真实写入端，再接入投影。此面板不改变任务状态、解锁 HOLD、补造 oracle 证据或代替 Captain 仲裁。
