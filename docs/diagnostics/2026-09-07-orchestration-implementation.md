## 审阅凭证与迁移

协议/人格模板版本为 6。旧 ACCEPT 和旧 gate 缺少新绑定时明确返回 GATE_STALE，保留历史判决；需要针对当前候选另开循环、提交 GREEN、获取新的最终审阅和 gate。旧 gate 不能被新任务 attempt 兑现。仅有早期 ACCEPT、最后一步只有 checkpoint 的任务不能完成。

冻结 oracle 的缺陷修正只允许显式关闭仍停在拒绝回退位置的旧循环，并在 oracle 与 cycle 两侧保存匹配的审计记录；已经开始修复的 GREEN 不会因残留 reject 字段被误关闭。DoD 自己改写候选时，其首次结果不能落入成功缓存，避免恢复原候选后复用污染结果。

## 尚未承诺的保证

- 快照检测运行前后的净变化，并非文件系统隔离。先改后恢复的 ABA、环境变量、忽略文件、外部依赖与 shell 后代仍有边界。
- 信箱历史保留完整内容；全文件扫描和租约重写仍随历史增长。单次通知有界不等于磁盘与解析成本有界。
- 同一共享工作区仍只有一个生产代码写者。真正多 Driver 的 worktree、读写集合、串行整合方案已写入研究，不伪称本轮已经实现。
- 真正的正确率增益需要留出任务对照。小型原生 smoke 只能证明该模型和宿主上的功能链路。
